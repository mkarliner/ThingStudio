Thingstudio

Start it:     ./thingstudio          (Windows: thingstudio.cmd)
Stop it:      Ctrl-C
Options:      ./thingstudio --help

The editor opens in your browser. The docs are at http://127.0.0.1:8765/docs/ while it runs.
Your flows and settings live in ~/.thingstudio (Windows: %USERPROFILE%\.thingstudio), outside this
folder, so replacing or deleting this folder never touches them.

This folder is self-contained: it carries its own Python. Nothing else needs installing.
