    Node catalog

    This is the flow-file reference. It lists every node a .flow.json can use, with the exact names a flow file needs: the node's type, its ports, and its properties with their types, defaults and allowed values. The editor's code generates it, so it matches what the compiler accepts.

    It does not explain how to use a node. Each entry links to the node's page, which says what the node does and what each property means. To build a flow in the editor, start from the node reference. To write or check a flow file without the editor, see Check a flow without the editor and AI authoring.

    In a flow file a node's type is thingstudio/ followed by the type shown here: wifi_status is written thingstudio/wifi_status. A property's editor label is the name the node's page uses for it. A port described as "message, payload bool" carries a message whose payload is a bool.

    Ports are numbered from 0 in a flow file's edges: [fromNodeId, outputNumber, toNodeId, inputNumber], in the order listed here.

    adc

    Type: adc. Kind: source. Palette group: hardware.

    Properties explained: adc

    • Inputs: none
    • Outputs: message, any payload
    Property Editor label Type Default Allowed values and notes
    pin pin number 34 the ADC pin to read; on ESP32, use an ADC1 pin if the flow uses WiFi (ADC2 can't with the radio on)
    mode mode string "relative" one of relative, absolute; relative (current value +- delta) or absolute (lower..upper)

    upper upper number 50000 absolute mode: the high bound
    sense sense string "outside" one of outside, inside; outside (fire when the value leaves the bounds) or inside (fire when it returns)
    pollMs poll (ms) number 0 also send every this many ms; 0 = only on a bounds crossing

    Config nodes

    A config node is listed under configs in a flow file as {id, type, properties}, with the full type shown here. A node names it by id in a property such as i2cConfigId. Credentials are saved by name (credentialName), never as secrets in the file.

    BLE

    Type: thingstudio/config/ble (one per flow).

    • name, text: What other devices show when they find the board, up to 26 bytes. Shorter leaves more room in an advertisement.

    Defaults: {"name":"thingstudio"}

    BLE peer

    Type: thingstudio/config/ble-peer.

    • addr, text: aa:bb:cc:dd:ee:ff. Leave blank to find the device by its name instead.
    • namePrefix, text: Used when there's no address. Phones change their address; most sensors don't.
    • timeoutMs, number: How long finding and connecting may each take before it tries again.

    Defaults: {"addr":"","namePrefix":"","timeoutMs":10000}

    GUI theme

    Type: thingstudio/config/gui-theme.

    • preset, select: one of dark-slate, light-paper, vivid, ``; Choosing a starting point replaces the colours below; editing one makes the theme custom.
    • bg, colour
    • card, colour
    • fg, colour
    • muted, colour
    • track, colour
    • accent, colour
    • on_accent, colour
    • ok, colour
    • warn, colour
    • alarm, colour

    Defaults: {"preset":"dark-slate","bg":4258,"card":8484,"fg":65535,"muted":35953,"track":16904,"accent":16113,"on_accent":2113,"ok":15974,"warn":64608,"alarm":63488}

    I2C bus

    Type: thingstudio/config/i2c-bus.

    • bus, number
    • scl, pin
    • sda, pin
    • freq, number: 100000 suits most sensors; 400000 for displays that can take it.

    Defaults: {"bus":0,"scl":null,"sda":null,"freq":100000}

    MQTT Broker

    Type: thingstudio/config/mqtt-broker (one per flow).

    • credentialName, credential

    Defaults: {"credentialName":""}

    Touch panel

    Type: thingstudio/config/touch-panel.

    • controller, select: one of ft6336u; Other controllers (GT911, CST820) aren't supported yet.
    • i2cConfigId, configRef: the id of a thingstudio/config/i2c-bus config
    • address, text: 7-bit, e.g. 0x38.
    • rstPin, pin: Blank if the panel has none.
    • pollMs, number
    • width, number
    • height, number: The panel's own size. If the display is rotated, tick swap/flip until a touch lands where you pressed.
    • swapXY, boolean
    • flipX, boolean
    • flipY, boolean

    Defaults: {"controller":"ft6336u","i2cConfigId":"","address":"0x38","rstPin":"","pollMs":20,"width":320,"height":480,"swapXY":false,"flipX":false,"flipY":false}

    WiFi

    Type: thingstudio/config/wifi (one per flow).

    • credentialName, credential
    • security, select: one of password, open, unmanaged
    • allowReprovisioning, boolean: Off by default: the device only opens its setup AP on first run. Turning this on lets it reopen that AP any time WiFi drops, not just once -- only do this on a trusted, physically-controlled network. Anyone in radio range while WiFi is down could otherwise connect to the AP and redirect this device to a different network.

    Defaults: {"credentialName":"","security":"password","allowReprovisioning":false}
