This session is about general cleanup of the editor ui and implementing features for more space for the flow canvas , such as collasible or hiddened panels.

This are suggested features, you may suggest alternatives

- remove bare-minimum text and header, we are now going to mvp/alpha
- make compiled code collapsed by default, its generally not interesting
- make panels able to be collapse or hidden.
- node properties should be revealed when a node is selected, otherwise out of the way
- the node list should be grouped, and custom nodes are allowed to specify a new group they should be in. the default node groups are
    - general
    - network
    - hardware
