# bme280

Reads a BME280 or BMP280 temperature, humidity and pressure sensor at a fixed interval.
[Supported hardware](../supported-hardware.md#sensors) lists the chips.

## Properties

- **I2C bus** — the bus the sensor is wired to. See [I2C bus](i2c-bus.md).
- **address** — `0x76` (most boards) or `0x77`.
- **interval (ms)** — how often to read. At least 100.

## Wiring

**Output** — one reading per interval:

```python
msg = {'payload': {'temperature': 21.43, 'humidity': 48.2, 'pressure': 1012.6}, 'topic': ''}
```

Temperature is in °C, humidity in %, pressure in hPa. On a BMP280, `humidity` is `None`.

To use one reading, pick it out in a [function](function.md) node:
`msg['payload'] = msg['payload']['temperature']`.

## Behavior

The status dot shows whether the sensor is answering. The node tries again at the next interval, and picks up a
sensor connected after the flow starts.

## Errors

If a read fails, the node sends nothing and the dot says why:

- **disconnected**, `no reply at 0x76 on I2C bus 0` — nothing answered. Check the wiring, pins and address.
- **error**, `no BME280/BMP280 at 0x76 (chip id 0x..)` — a different chip is at that address.
