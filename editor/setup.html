Set up a board

This page puts MicroPython on a board so ThingStudio can use it. It runs in your browser: the board is reached over the USB cable, and nothing is sent anywhere.

Writing a new image erases everything on the board, including a flow and its settings.

This browser can't reach a USB board. Use Chrome or Edge on a desktop computer. A Pico or nRF52 board still works from any browser: choose it below and drag the file it gives you.

Which kind of board?

Plug the board in with a USB cable that carries data, then click Connect and pick its port.

If the port doesn't appear, or Connect fails: hold the BOOT button, tap RESET, release BOOT, and try again. Some boards need a USB serial driver first.

    Then: install the ThingStudio runtime

    For a board that runs MicroPython, including one you've just written above. Plug it in, click Install runtime and pick its port. This restarts the board.

    A board that already has a flow keeps it. If the page waits, press the board's reset button.

    Other boards: get MicroPython from micropython.org/download and follow its instructions.
